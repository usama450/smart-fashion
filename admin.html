One-time Supabase Setup

Your images now upload to the cloud so everyone sees them. This takes about 5 minutes and is completely free.

1 Create a free Supabase account

Go to supabase.com → click Start your project → sign up with GitHub or email.

Then create a new project. Pick any name (e.g. "smart-fashion"). Choose a strong database password and save it somewhere.

2 Run the database setup SQL

In your Supabase dashboard, go to SQL Editor → New query, paste and run the contents of setup.sql (included in your project folder).

It creates the products table, enables security, and sets read/write permissions.

3 Create the image storage bucket

Go to Storage → New bucket. Name it exactly: product-images. Toggle Public bucket ON. Click Save.

4 Enter your project credentials below

In Supabase: go to Project Settings → API. Copy the Project URL and anon public key.

Please fill in both fields.
